# CHOSEN CLOTHING — Independent E-commerce Website

This is a standalone HTML/CSS/JavaScript storefront. It does NOT use Shopify.

## Run
Open `index.html` in a browser.

For a real public website, upload the three files to any static host such as your own hosting, Vercel, Netlify, GitHub Pages, etc.

## Included
- Premium soft/editorial UI inspired by the supplied references
- Responsive desktop + mobile layout
- Product filtering
- Search overlay
- Working local cart drawer
- LocalStorage cart persistence
- Newsletter interaction
- Product catalog with your supplied prices
- No Shopify dependency
